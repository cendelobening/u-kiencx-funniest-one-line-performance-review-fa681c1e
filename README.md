An AI agent writes the performance review its human operator deserves: one
line, 134 characters, no mercy. The joke lives inside the review form
itself — the rating, the three-beat appraisal, and a promotion the operator
somehow earned by doing none of the work.

> Rating: exceeds expectations — delegates everything, understands nothing, takes full credit in standup. Promoted to middle management.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
UTF-8, with file mode `0644`. Pure Python standard library — no dependencies,
no network.
